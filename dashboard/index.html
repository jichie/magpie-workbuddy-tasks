看板密钥

除 /api/hello 外，所有接口都需要守护进程密钥。密钥保存在浏览器 sessionStorage（只发往本机守护进程），也可以用 ?k=<key> 打开本页。

密钥在 <magpie 配置目录>/workbuddy-tasks/state/daemon.json 的 key 字段里（文件权限 0600，实际端口也写在同一文件）。

启动守护进程

浏览器无法拉起本机进程。magpie 开启本插件时会自动拉起守护进程；如需手动启动， 在插件目录的终端里执行： 

node daemon.mjs
# 或 bun daemon.mjs
# 可选：--port 4390 --addr 127.0.0.1 --cfg <magpie 配置目录> --state <状态目录>

启动后看板在 http://127.0.0.1:4390/（端口被占用会自动顺延）； 实际端口与密钥写在 <状态目录>/daemon.json。
